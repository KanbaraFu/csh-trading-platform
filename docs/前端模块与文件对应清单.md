# 前端模块与文件对应清单

> 项目：淘学二手 · 校园二手交易平台（前端）
> 技术栈：Vite 8 + Vue 3 + Element Plus + Pinia + vue-router
> 文档用途：把《校园二手交易平台项目开发文档》中的 6 个模块（A~F）逐一对应到前端的 Vue / JS 文件，便于分工、联调与验收。
>
> ⚠️ **路径基准**：本仓库为 monorepo，文档中所有 `src/**` 路径均指 **`frontend/src/**`**；前端命令需在 `frontend/` 目录下执行。

---

## 0. 一句话结论

前端按 **「模块 → API 层 → Store → Mock → 页面/组件」** 五层组织。每个业务模块都有一份 `api/*.js` 与（除 F 外）一份 `store/*.js`；页面通过 Store 间接调用 API，Mock 层与后端接口路径保持一一对应。

---

## 1. 总览：模块 → 核心 JS 文件

| 模块 | 名称 | API 层 | Pinia Store | Mock 层 | 常量 / 工具 |
| ---- | ---- | ------ | ----------- | ------- | ----------- |
| A | 用户与认证 | `src/api/auth.js` | `src/store/user.js` | `src/mock/modules/user.js` | `src/constants/auth.js`、`src/constants/address.js` |
| B | 商品与分类 | `src/api/product.js` | `src/store/product.js` | `src/mock/modules/product.js` | `src/constants/product.js`、`src/utils/image.js` |
| C | 收藏与购物车 | `src/api/favorite.js`、`src/api/cart.js` | `src/store/favorite.js`、`src/store/cart.js` | `src/mock/modules/cart.js`（收藏部分在 `product.js`） | — |
| D | 订单与交易 | `src/api/order.js` | `src/store/order.js` | `src/mock/modules/order.js` | `src/constants/order.js` |
| E | 互动与消息 | `src/api/message.js` | `src/store/message.js` | `src/mock/modules/interaction.js` | `src/constants/message.js` |
| F | 搜索与统计 | `src/api/stat.js` | 无独立 Store（页面直连 API） | `src/mock/modules/interaction.js` | — |

> **两个易踩坑点：**
> 1. 前端**没有** `api/search.js`，搜索与热词接口被放在 `src/api/stat.js`（`search` / `getHotWords`）。
> 2. Mock 层里 **E、F 两个模块共用** `src/mock/modules/interaction.js`；**收藏接口**（`/favorites/**`）也在 `src/mock/modules/product.js` 中实现，而不是 `cart.js`。

## 8. 跨模块页面速查

一个 Vue 文件往往同时归属于多个模块，联调时需注意多方改动。

| Vue 文件 | 涉及模块 |
| -------- | -------- |
| `src/views/ProductDetailView.vue` | B（详情）+ C（加购 / 收藏）+ E（评论）+ F（浏览量 / 销量） |

| `src/views/HomeView.vue` | B + F |
| `src/views/CategoryView.vue` | B + F |
| `src/views/LoginView.vue` | A（主）+ 登录后拉取 C / E 的计数初始化 |
